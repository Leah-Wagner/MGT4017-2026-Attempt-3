# Cooking Cheap website
Responsive static website prototype for the Cooking Cheap concept.

## Files
- `index.html`: website content and sections
- `style.css`: layout, styling, and responsive breakpoints
- `script.js`: menu, meal-plan demo, store lookup, plant helper
- `assets/`: image crops from the provided design screenshots

## Preview locally
Open `index.html` in a browser. This project does not require Node, a framework, or a build step.


## Deploy with GitHub Pages
1. Upload all files and folders in this project to the root of your GitHub repository. Ensure `index.html` is at repository root.
2. Open **Settings → Pages** in GitHub.
3. Under Build and deployment choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)` and Save.
5. After deployment completes, open the Pages URL shown in repository settings.


## Prototype notes
- Meal suggestions are generated from a small built-in list and are not nutrition- or price-verified.
- The map search opens Google Maps results for the town/postcode typed; it does not request location permission.
- Plant Helper is a basic keyword-based response tool, not a live AI or plant diagnosis.
- Replace the placeholder contact email before publishing.
